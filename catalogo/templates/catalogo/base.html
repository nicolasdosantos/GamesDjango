{% load static %} {% comment %} base.html: o "molde" de todas as páginas do site. Ele tem o que se repete em todo lugar (head, menu, rodapé) e deixa "buracos" chamados blocks. As outras páginas começam com {% extends 'catalogo/base.html' %} e só preenchem esses blocks. Isso é a herança de templates: se eu mudar o menu aqui, ele muda em todas as páginas. Nenhuma view renderiza este arquivo direto, ele sempre vem por meio de um extends. Na linguagem de templates do Django tem dois tipos de marcação: - {{ variavel }} MOSTRA um valor na página (ex: {{ jogo.titulo }}). Pode ter filtro com |, tipo {{ jogo.titulo|upper }}. - {% tag %} faz uma AÇÃO ou lógica: if, for, url, block, extends, include... e não mostra nada sozinha.
